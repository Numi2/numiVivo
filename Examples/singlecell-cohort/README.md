# From count libraries to paired-donor expression analysis

The complete fixture is generated by the native executable. It has six synthetic
donors, two conditions, 32 features, 24 nonempty cells and 12 empty barcodes. The
first three genes have a declared count increase in the treated condition. This
is an executable integration example, not experimental measurements or a
statistical calibration dataset.

```sh
swift build -c release
BIN=.build/release/numivivo
RUN="$(mktemp -d "${TMPDIR:-/tmp}/numivivo-cohort.XXXXXX")"
"$BIN" singlecell-example --output "$RUN/example"
"$BIN" singlecell-run "$RUN/example/manifest.json" \
  --store "$RUN/store" --output "$RUN/counts.json"
"$BIN" singlecell-analyze "$RUN/counts.json" \
  --plan "$RUN/example/analysis.json" \
  --store "$RUN/store" --output "$RUN/analysis.json"
"$BIN" singlecell-analysis-verify "$RUN/analysis.json" --store "$RUN/store"
"$BIN" singlecell-analysis-export "$RUN/analysis.json" \
  --store "$RUN/store" --output "$RUN/report.json"
"$BIN" singlecell-analysis-tables "$RUN/analysis.json" \
  --store "$RUN/store" --output "$RUN/tables"
"$BIN" singlecell-analysis-mex "$RUN/analysis.json" \
  --store "$RUN/store" --output "$RUN/selected-counts"
```

The default quality filter requires at least one count and one detected feature.
All 36 source decisions remain in the report; the 12 empty barcodes are excluded
from the selected matrix. All feature identities remain intact. The paired model
uses 12 donor-condition pseudobulks, not 24 independent cell observations. Its
design has an intercept, treatment effect and five donor indicator columns, with
five residual degrees of freedom. The example sets two cells per pseudobulk;
production defaults require ten, but neither threshold is a power calculation.

The TSV directory contains `cell-quality.tsv`, `feature-statistics.tsv`, a table
for each contrast, the corresponding explicit design matrix, and `index.json`
binding exported tables to the analysis receipt. Missing or untested values are
empty fields, not zero. The MEX directory contains exact selected raw counts,
metadata, cell-group annotations, and row-mapping sidecars. It can be reimported
with `singlecell-run selected-counts/manifest.json` and the usual store/output
options. No production Python or R process is invoked.

## Use declared experimental metadata

Keep the import manifest and analysis plan separate. Source files may be plain
UTF-8 or gzip-compressed MEX. Gzip is detected from the bytes, checksums and total
expanded-byte limits are enforced, and original compressed bytes are archived.
All libraries still require the same ordered Gene Expression feature dictionary;
there is no implicit gene-ID reconciliation or automatic modality filtering.

An analysis plan contains `schemaVersion`, `id`, `filter`, `normalizationTarget`
and `contrasts`. Each contrast names its two conditions and a supplied `cellGroup`.
Omitting `cellGroup` selects unassigned cells, not all groups pooled together.
`pairedDonors` requires one usable pseudobulk in both conditions for every selected
donor. Independent replication rejects repeated donor/replicate identities. Small
pseudobulks are reported as excluded, and incomplete pairs or rank-deficient batch
designs are rejected. Batch adjustment is on by default; mixed-batch pseudobulk
rows cannot be assigned a fabricated single batch.

`medianRatio` uses genes positive in all selected pseudobulks, requiring at least
10 by default. It never silently falls back to library-size normalization.
`librarySize` can be declared explicitly. The model fits
`log2(rawCount / sizeFactor + priorCount)`; default prior count is 0.5.
Empirical-Bayes moderation requires at least 20 positive residual variances.
An ordinary, unmoderated model can be declared explicitly. Neither path is a
negative-binomial model, voom implementation or mixed-effects model.

The workflow adapter is `vivo.platform.singlecell-analyze`, version `1`, with
stored inputs `input` (`vivo.singlecell-input-bundle-v1`) and `plan`
(`vivo.singlecell-analysis-plan-v1`), empty configuration and output `report`
(`vivo.singlecell-cohort-report-v1`). The dedicated CLI and this adapter use the
same native analysis authority. `Tools/Omics/check_analysis_cli.py` exercises the
adapter, MEX round trips, compressed sources, exports and false-artifact rejection.

Receipts are executable/OS-bound. After rebuilding, regenerate the count receipt
with that executable before producing or verifying a new analysis. No stored
artifact is relabelled to bypass that requirement.
