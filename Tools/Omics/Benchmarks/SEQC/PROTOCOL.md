# SEQC technical effect validation — frozen before fitting

Use seqc 1.46.0, source archive SHA-256 `f54700f7ef029225455f8f6c83bf0211d106f68dc9656ed9ab9d7f82b5cce7ea`, downloaded from `https://bioconductor.posit.co/packages/release/data/experiment/src/contrib/seqc_1.46.0.tar.gz`. Include all six Illumina RefSeq tables: AGR, BGI, CNL, COH, MAY and NVS. Retain every source gene row and its EntrezID, symbol, length and ERCC flag. Table/column schemas and the published vignette were inspected; no qPCR A/B effects or RNA-seq fit outcomes have been inspected at this freeze.

Analyze B versus A independently within each site. Sum every lane/flow-cell count belonging to the same sample letter and preparation replicate. Retain the complete original column-to-library map and integer sums. Libraries are technical preparations of reference RNA, not independent human donors. Do not count lanes as replicates, infer pairing across A/B, or combine sites as independent biological studies. Preserve all source A/B preparations; fewer than three per arm is unavailable, not a reason to substitute another site.

Run the unchanged native NB cohort owner with independent-replicate design, median-ratio size factors, Gamma-parametric dispersion trend, minimum 20 trend genes, minimum prior variance 0.25, outlier threshold 2 SD, minimum 10 total counts and three expressing libraries. Set the legacy minimum-observation-membership threshold to one: each adapter row is one complete bulk library preparation, not a fabricated single cell. Identify these technical units explicitly, with no donor IDs. Retain Wald/MLE and optional weighted-upper-quantile empirical contrast shrinkage from the same fit. Withheld genes and failed priors/fits remain unavailable. No tuning from qPCR outcomes, feature aliases or default promotion.

Freeze all native input/output hashes before loading qPCR effect values for scoring. Match qPCR and count rows only by literal, nonmissing EntrezID occurring exactly once in each source. Require positive finite qPCR values and `P` detection in all four A and all four B measurements. The reference effect is mean(log2 B intensity) minus mean(log2 A intensity). Retain every excluded reference row and reason. This is an independent measurement reference, not error-free biological truth.

For each site and native method, report reference coverage, Spearman/Pearson correlation, raw log2-effect RMSE/median absolute error, median signed error, and directional agreement among reference effects with absolute magnitude at least one. The predeclared descriptive gate requires at least 90% coverage, Spearman >= 0.90 and at least 90% directional agreement in each site. Do not change the gene family to improve a result. Separately report a common available family for method comparisons without replacing original inventories. Cross-site observations share the same RNA materials and qPCR reference; do not pool them into an IID confidence interval.

Compare pinned edgeR, limma-voom and DESeq2 on the exact same library counts and design, recording package versions, normalization and full status inventories. Matched native size factors are the primary reference normalization; package defaults may be separately labeled sensitivities. Freeze reference estimates before scoring them too. Numerical agreement and measurement correlation do not establish false-discovery control, interval coverage, intervention prediction, biological replication or clinical validity. This benchmark begins bulk-RNA technical validation on the common count-model foundation; it does not complete the broader goal.
