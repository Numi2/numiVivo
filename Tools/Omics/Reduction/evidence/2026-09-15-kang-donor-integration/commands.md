# Reproduction boundary

The current native route is `singlecell-h5ad-pca` followed by
`singlecell-pca-integrate` and `singlecell-pca-integrate-verify`, using the
retained PCA bundle, `integration-plan.json` and the current binary. The
compact receipt retains the applied plan, solver report, implementation-bound
receipt, PCA receipt and integration log; large score and membership arrays
are not committed.
