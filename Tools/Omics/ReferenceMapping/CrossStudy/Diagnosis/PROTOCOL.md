# Post-result transfer diagnosis

This diagnostic begins after the complete Kang–Ding transfer failed both frozen
coarse-family targets. It is exploratory, with no classifier refitting, cohort
selection, source relabelling or changes to the original gates and predictions.
All 68,704 query cells remain represented. Source annotation and biological
identity are distinct evidence claims.

Trace the literal megakaryocyte classes through original category codes, prepared
labels and frozen native models. Check every Kang original cell label against the
prepared source. Measure training-set recall only as an in-sample diagnostic.
Record selected features and the exact linear gene-space coefficients implied by
PCA plus standardization plus multinomial logistic regression.

Use native standalone program scoring for two explicitly analyst-selected,
post-result gene means: HBB/HBA1/HBA2 and PF4/PPBP/ITGA2B/GP9/TUBB1. Weights are
all one, normalized by total absolute member weight; normalize complete measured
RNA libraries to 10,000 before log1p. These scores describe measured transcripts,
not cell identities, protein abundance or validated pathways. Require all members
and preserve all source cells, labels, genes and library totals. Reconstruct native
bundles and compare every score, detection count and total to independent sparse
arithmetic. Retain distributions by every original label and library.

For each frozen model, decompose the mean literal-megakaryocyte-versus-CD4-T logit
margin into the contribution of every selected gene plus the intercept. The CD4
rival is chosen because it dominates the observed errors; this choice is post hoc.
Require the gene-space affine reconstruction to agree with the frozen PCA model
for every query cell. Compare query and training means of the literal source
class without asserting that those names establish equivalent identities. Rank
signed gene contributions to the difference in mean margin; no marker threshold,
new label, exclusion, calibration or repaired model is chosen from these outcomes.

Known original count/identity and numerical evidence stays intact. A prior paper's
uncertainty about an annotation can support an evidence limitation; it cannot
supply cell-by-cell replacement identities for this source. Preserve failed
lookups and do not retry challenged/rate-limited access routes.
