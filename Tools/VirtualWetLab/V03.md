# Spatial response learning — v0.3 working increments

NumiVivo retains the complete GSE274447 spatial RNA cohort: 229,775 cells,
source guide assignments, barcode-negative and multi-guide missingness,
15-neighbor relationships, inferred reference labels and source-axis masks.
Seven guide targets meet the fixed count threshold; all exclusions are retained.
Clu is previously exposed development evidence, never independent validation.

Supplementary Data 3 exact cell totals bind chip 1 to mouse 1, chip 2 to pooled
mice 2 and 3, and chip 3 to mouse 4. Chip 2 is one indivisible training block;
chip 3 is validation and chip 1 test. No per-cell section identity is invented.
The supplement conflicts about chip 2 section count; geometry-based neighborhoods
therefore remain unqualified anatomical assignments. GEO's mouse labels are not
substitutes for biological-unit identity.

Reference RNA comes only from isolated mSafe cells and separately labelled
barcode-negative control-associated neighbors. Negative barcode does not imply
unexposed. All references adjacent to noncontrol or ambiguous guide anchors are
excluded. Query labels are uncertain control-reference projections, not measured
cell types; distant references cannot produce a supported label.

The first trained attempt erroneously admitted mSafe cells near other guides.
It is retained as invalid-reference evidence, with no test response reveal.
After correction, the test chip has only four isolated mSafe controls. This fails
the preregistered minimum of five for biological qualification. Exploratory
execution does not waive this gate. There are only three independent split
blocks, one pooled; genes and neighborhoods are not independent animals.

## Local reproduction

Use a Python environment with anndata, h5py, scipy, scikit-learn and safetensors.
`prepare_spatial_cohort.py --sources SOURCE_GEF_DIRECTORY --output COHORT`
retains all measured RNA. Then
`prepare_spatial_learning.py --cohort COHORT --output INPUTS` writes control-only
query tensors and the preregistration before fitting.
`check_spatial_cohort.py --cohort COHORT --inputs INPUTS --sources SOURCE_GEF_DIRECTORY --output CHECK.json`
checks every neighbor and query reference plus 64 exact source RNA rows per chip.

Build the existing MLX product with `Tools/run-numivivo-mlx.sh help`.
`train_spatial_response.py --inputs INPUTS --binary NATIVE_NUMIVIVO` runs the fixed
three-checkpoint budget. `numivivo spatial-response train|predict PLAN INPUT OUTPUT [WEIGHTS]`
uses the existing `VivoCellResponseMLXModel`, not a second neural implementation.
Cell projection, shared perturbation embedding, spatial descriptor encoder,
response decoder and diagonal variance head are native MLX. Native queries contain
no response observations. The endpoint distribution is in log1p(CPM), at fixed
measured geometry; it does not describe a specific cell's trajectory.

The frozen Nicheformer representation experiment uses only admitted references.
Its mouse/human vocabulary is mapped through one-to-one MGI homology and NCBI
Ensembl identifiers. Stereo-seq has no pretrained technology token, so this
branch is explicitly out of distribution. It is not itself a perturbation model.

Software release qualification and biological promotion remain separate.
The v0.2 immutable adapter files and failed Clu record remain unchanged.
