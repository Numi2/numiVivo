# Spatial response learning — v0.3 working increments

NumiVivo retains the complete GSE274447 spatial RNA cohort: 229,775 cells,
source guide assignments, barcode-negative and multi-guide missingness,
15-neighbor relationships, inferred reference labels and source-axis masks.
Seven guide targets meet the fixed count threshold; all exclusions are retained.
Clu is previously exposed development evidence, never independent validation.

Supplementary Data 3 exact cell totals bind chip 1 to mouse 1, chip 2 to pooled
mice 2 and 3, and chip 3 to mouse 4. Chip 2 is one indivisible training block;
chip 3 is validation and chip 1 test. No per-cell section identity is invented.
The supplement conflicts about chip 2 section count; geometry-based neighborhoods
therefore remain unqualified anatomical assignments. GEO's mouse labels are not
substitutes for biological-unit identity.

Reference RNA comes only from isolated mSafe cells and separately labelled
barcode-negative control-associated neighbors. Negative barcode does not imply
unexposed. All references adjacent to noncontrol or ambiguous guide anchors are
excluded. Query labels are uncertain control-reference projections, not measured
cell types; distant references cannot produce a supported label.

The first trained attempt erroneously admitted mSafe cells near other guides.
It is retained as invalid-reference evidence, with no test response reveal.
After correction, the test chip has only four isolated mSafe controls. This fails
the preregistered minimum of five for biological qualification. Exploratory
execution does not waive this gate. There are only three independent split
blocks, one pooled; genes and neighborhoods are not independent animals.

## Local reproduction

Use a Python environment with anndata, h5py, scipy, scikit-learn and safetensors.
`prepare_spatial_cohort.py --sources SOURCE_GEF_DIRECTORY --output COHORT`
retains all measured RNA. Then
`prepare_spatial_learning.py --cohort COHORT --output INPUTS` writes control-only
query tensors and the preregistration before fitting.
`check_spatial_cohort.py --cohort COHORT --inputs INPUTS --sources SOURCE_GEF_DIRECTORY --output CHECK.json`
checks every neighbor and query reference plus 64 exact source RNA rows per chip.

Build the existing MLX product with `Tools/run-numivivo-mlx.sh help`.
`train_spatial_response.py --inputs INPUTS --binary NATIVE_NUMIVIVO` runs the fixed
three-checkpoint budget. `numivivo spatial-response train|predict PLAN INPUT OUTPUT [WEIGHTS]`
uses the existing `VivoCellResponseMLXModel`, not a second neural implementation.
Cell projection, shared perturbation embedding, spatial descriptor encoder,
response decoder and diagonal variance head are native MLX. Native queries contain
no response observations. The endpoint distribution is in log1p(CPM), at fixed
measured geometry; it does not describe a specific cell's trajectory.

The frozen Nicheformer representation experiment uses only admitted references.
Its mouse/human vocabulary is mapped through one-to-one MGI homology and NCBI
Ensembl identifiers. Stereo-seq has no pretrained technology token, so this
branch is explicitly out of distribution. It is not itself a perturbation model.

Software release qualification and biological promotion remain separate.
The v0.2 immutable adapter files and failed Clu record remain unchanged.

## Completed experiment and outcomes

The final source-bound campaign fits seven interventions: Cfap410, Clu, Fasn,
Gfap, Rraga, Stk39 and Trem2. It predicts separate directly perturbed and
barcode-negative neighboring endpoint distributions. All surrounding measured
RNA is retained, but only admitted reference RNA enters prediction inputs.

All variants reuse `VivoCellResponseMLXModel` (64 hidden units). Cell state and
reference-neighborhood PCA descriptors condition its shared perturbation embedding
and full-axis mean/variance decoder. The frozen Nicheformer branch replaces these
descriptors with a training-reference PCA projection of official frozen embeddings.
The original official pooling is preserved; missing Stereo-seq technology remains
out of distribution. MPS masked attention stalled locally; offline frozen
embedding extraction succeeded on Apple CPU. Native response training and
inference use MLX/Metal. No architecture-size search was performed.

Validation selected step 240 from the declared 240/720/1440 budget for all final
variants. Test observations were revealed only after their predictions and the
external comparator were sealed. The first contaminated-reference attempt remains
retained separately and was not unblinded.

| Method | Held-out equal-target population-group RMSE |
|---|---:|
| No change | 0.736076 |
| Upstream State PerturbMean | 0.756027 |
| Native neighborhood model | 0.761057 |

These are mean per-cell log1p(CPM) endpoint comparisons on the common measured
training/test gene axis, aggregated equally over population groups and targets.
They are not numerically comparable to v0.2's different pseudobulk/target task.
Direction agreement, effect-size bias, Gaussian NLL, training-panel Wasserstein,
marginal coverage, per-target/type/neighborhood/role errors and failure diagnostics
are retained in `evidence/v03/model-evaluation.json`. Marginal coverage is not a
calibrated biological confidence interval. Baseline point predictions do not
receive invented variance. Clu remains previously exposed evidence.

**Biological promotion fails.** The native model loses to no change. Tiny aggregate
differences between spatial, spatial-free and shuffled variants do not establish
useful neighborhood benefit. Four isolated test controls also fail the declared
minimum five. There is one held-out animal, not hundreds of independent biological
replicates. The legacy donor-ridge model requires at least two independent training
units; this split has one pooled block. It is unavailable here rather than fitted
to falsely relabelled regions. Its v0.2 regression still replays unchanged.

The Cfap410 model excludes that target from training, but the initial driver
included its validation responses in checkpoint selection. The retained result is
therefore **exploratory transfer of an unseen training target**, not clean unseen-
perturbation qualification. `qualification-audit.json` records this limitation;
no new independent-validation claim is made after test reveal.

The pinned external State comparator is its actual upstream PerturbMean baseline,
refit on the same mouse log-expression distribution means, on CPU. Its
CC-BY-NC-SA-4.0 code is retained outside the native product. This is not a
reproduction of the full State ST benchmark. PRiMeFlow informs distributional
methodology; no claim of reproducing that model is made.

## Investigation and replay

`learned_spatial.build(INPUTS, NATIVE_BINARY, OUTPUT)` prepares an assay consumed by
NumiLab's existing experiment service. The concrete learned assay uses the same
adapter lifecycle as v0.2, without changing any immutable v0.2 adapter file.
The workspace compares multiple interventions against one common population
reference and seals their direct/neighbor arms together. Source measurements are
revealed afterwards, evaluated, separately sealed, and verified on replay.
Population overlays do not claim cell-specific trajectories. Raw measured UMIs,
normalized values, unmodeled markers, inferred labels and insufficient support
remain visibly distinct. Completed-campaign diagnostics are labelled separately
from a new retrospective comparison's reveal.

Local lifecycle checks cover hidden observations, common controls, unsupported
target rejection, unmodeled-marker unavailability, query/evaluation tampering,
correct residual sign, bit-exact native mean/variance replay and evaluation
reconstruction. Complete native retraining of the no-neighborhood variant also
reproduced every parameter tensor at all three checkpoints bit-exactly on this
Mac. Cross-hardware bit identity is not claimed. Fifteen existing contract tests
pass; the original v0.2 failed Clu record remains independently replayable.

The release package contains selected weights for all five native variants,
control-only queries, plans, sealed predictions, native Apple-silicon runtime and
Metal bundle, experiment record, qualification results and browser evidence.
`package_spatial_release.py --evidence EVIDENCE_ROOT --output RELEASE_DIRECTORY`
produces a SHA-bound archive. Native inference can replay directly from this
package; full source-record replay additionally requires the retained GEO cohort.
Training is reproduced from the source ingestion and fixed training invocation
above, with seed 314159. No paid CI jobs were added.

## Arc qualification is separate

`arc_local_evaluation.py` executes pinned `ArcInstitute/cell-eval2` revision
`0ce25cf4c495e76e60dfca4ddc8f822507aa0e18`, official `vcc2026` preset, on real
GSE146194 human K562 CRISPRi measurements. Eight targets are chosen by deposited
QC/support and lexical order before expression inspection. A raw-count no-change
prediction artifact is sealed before scorer execution. The official local API
requires a control label in both inputs; this is a separate wrapper around the
control-free prediction artifact, since the challenge upload format rejects
submitted controls. The initial incompatible local invocation is retained.

All six metric families execute. The official real-side gate omits fold-change
accuracy for two targets; omissions and scanpy warnings remain in the log. Local
scores, input identities and exact parameters are in `evidence/v03/arc-local`.
This checks the evaluator path on known K562 context; it does not qualify unseen
cellular-context prediction or spatial tissue response. Official 2026 submission
conformance and an actual challenge score remain **UNAVAILABLE**: `vcc datasets
list` reports `not_logged_in`, so the official control/gene/target bundle was not
available. No synthetic submission was relabelled as a biological evaluation.
