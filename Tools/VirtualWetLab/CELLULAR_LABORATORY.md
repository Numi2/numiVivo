# Cellular laboratory: first executable delivery

A frozen native cellular model now participates in the same NumiLab proposal,
revision-checked edit, preregistered objective, prediction seal, authorized reveal,
evaluation and replay workflow as the learned spatial assay. Geometry is optional.
This is the first delivery of the staged cellular/population-learning plan, not
completion of its later ingestion, training or external-comparator campaigns.

`laboratory.py` adds capability, selection validation, objective inspection,
readout and objective evaluation operations. Historical adapters are unchanged.
The cellular adapter calls the existing native prediction operation,
`train_cohort_recovery.measure` and `design_objective` scoring; it contains no
second neural model or scientific scoring implementation. Unsupported conditions,
interventions and objective features fail owner validation. Population means are
shown as population means, not trajectories or single-cell distributions.

## Frozen input and model

The initial artifact packages the existing transfer campaign's `held-target-0`
coarse-descriptor checkpoint, selected at 240 steps by its retained inner selector.
It retains 27 source/context/target queries, 516 features, source-qualified control
and outcome row identities, source hashes, preprocessing, target descriptors,
weights, native executable and Metal library. It covers GSE90063, GSE90546 and
GSE92872 contexts. This historical feature intersection is explicitly retained;
it is not the proposed heterogeneous-panel Replogle–Nadig importer.

All outcomes are already-exposed technical development data. Sealing a new card
does not turn these outcomes into an independent evaluation. Biological-unit and
additional guide identities remain unresolved. The native artifact uses the
historical single context-vector entry point. No new encoder, training, population-
input comparison, State Transition comparison or biological promotion is claimed.

Build from the retained prior campaign:

```sh
python Tools/VirtualWetLab/build_frozen_cellular.py \
  --campaign /path/to/retained/transfer/campaign \
  --output /path/to/durable/laboratory/artifacts/frozen-cellular
python Tools/VirtualWetLab/qualify_cellular_laboratory.py \
  --assay /path/to/durable/laboratory/artifacts/frozen-cellular/assay.json \
  --output /path/to/new/qualification.json
```

The builder verifies the existing selector and prediction seal; it does not fit
or select another model. The native qualification checks unsupported inputs,
selected-query equality to the frozen prediction, closed observations, authorized
comparison, exact replay after relocation and rejection of corrupted inputs.

## Executed shared experiment

A fresh Codex session discovered GSE90546 K562 through the installed plugin,
proposed FOS/JUN reduction with DDIT3 and SPI1, and left an editable visual card.
Browser keyboard automation changed the objective to FOS/JUNB. The session then
preserved that edit, rejected stale revision 11, retained and corrected an
unsupported condition, sealed the exact cellular model, explicitly revealed the
acceptance measurements and replayed the native prediction exactly.

The selected population has 1,769 distinct control cells, 477 DDIT3 outcome cells
and 696 SPI1 outcome cells. These counts are not independent biological units.
No intervention was both the predicted numerical choice and the best observed
eligible option for this objective. The descriptive regret was zero; this does
not demonstrate useful intervention prediction. The gene-level failure remains
visible: for DDIT3/FOS the model predicts about 0.0124 log1p(CPM), versus about
2.9710 measured, with signed residual about −2.9586.

A newly executed spatial card also completed the same lifecycle. Historical
spatial record b5a48f052e4946df94f84b7463f48005 still replays bit-exactly without
modifying its sealed owner implementations.

The exported laboratory includes native cellular artifacts and retained owner
code. The legacy spatial assay has explicitly hashed external source/runtime
and Metal-library dependencies. It is not a self-contained cross-machine package.
Restoration uses a separate location map; sealed registrations are never rewritten.
See NumiLab's `docs/virtual-wet-lab-cellular.md` and the retained qualification
receipts for the complete restoration and browser results.
