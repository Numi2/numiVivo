# Virtual Wet Lab v0.2: real spatial perturbation

The laboratory can now carry a real spatial specimen through selection, a typed
intervention, sealed native prediction, spatial/molecular readout, held-out reveal,
baseline comparison, evidence inspection and exact replay. NumiVivo owns state
and models; NumiLab renders and authors experiments. `laboratory.py` extends the
existing `WetLabExperimentAdapter` registry without changing the runtime-bound
RNA and synthetic transport adapters.

## The integrated experiment, including its failure

[Spatial Perturb-seq](https://www.nature.com/articles/s41467-026-69677-6) deposits
cell-segmented Stereo-seq RNA and guide barcodes for three source-labelled mice
in [GSE274447](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE274447).
The pinned [download manifest](spatial_perturb_sources.json) identifies all three
original GEF files. Coordinates, original cell IDs, raw UMI and biological units
survive ingestion into the shared [native tissue representation](TISSUE.md).

The frozen assay selects cells with exactly one positive guide species, Clu or
safe-harbour mSafe, following the deposited analysis's simple barcode rule. It
retains 620 cells and all 22,314 common named non-guide genes; unnamed GEF features
are excluded explicitly. Mice 1 and 2 train the existing native fixed-alpha
context-ridge predictor. Mouse 3 supplies only its regional control to prediction.
The native aggregate projection maps training populations to each query group;
it does not create additional mice or train a new spatial model.

A fixed 2×2 coordinate grid and minimum three cells in each arm were declared
before prediction. Only region-1-0 qualifies: four controls and 18 Clu cells.
The other three regions remain unavailable. Grid regions are not anatomical
annotations. Raw chip coordinates have no asserted micrometre transform.
The study endpoint is the only supported time; no trajectory is invented.

On the single eligible held-out region, all-gene response RMSE in log1p(CPM) was:

| Native model | RMSE |
|---|---:|
| Context ridge, primary | 1.8776936838672345 |
| No change | 1.8483054581598883 |
| Training mean | 1.9396783198541783 |
| Training median | 1.9396783198541783 |

The preregistered requirement to beat both no-change and training mean was
**contradicted**. The failed comparison is stored permanently. No parameter or
eligibility threshold was tuned after reveal. This demonstrates an executable,
auditable experimental loop, not validated spatial biology or state-of-the-art
prediction accuracy. Repeating this exposed cohort is development regression.

The first ingestion attempt rejected unnamed duplicated features in two GEFs.
Its failure receipt is retained. The subsequent preparation excludes unnamed
features rather than inventing gene identities; the fixed target, region and
minimum-cell rules were unchanged.

## Run and reproduce

Use Python with h5py, anndata, numpy, scipy and pandas for preparation and independent
checks. The adapter uses the standard library; predictions remain Swift-native.
Download the three original GEF files listed in `spatial_perturb_sources.json` to
one directory. Preparation verifies their pinned SHA256 digests.

```sh
export NUMIVIVO_HDF5_LIBRARY=/absolute/path/libhdf5.dylib
python Tools/VirtualWetLab/build_tissue.py --output /absolute/path/new-tissue-build
python Tools/VirtualWetLab/prepare_spatial_perturb.py \
  --sources /absolute/path/gef \
  --binary /absolute/path/numivivo \
  --tissue-binary /absolute/path/new-tissue-build/numivivo-tissue \
  --output /absolute/path/new-spatial-clu
numi wet-lab --vivo-root /absolute/path/numiVivo \
  --binary /absolute/path/numivivo \
  --assay /absolute/path/new-spatial-clu/assay.json \
  --workspace /absolute/path/experiments
```

The native RNA binary must expose `singlecell-h5ad-pseudobulk`,
`singlecell-perturbation-batch` and `singlecell-perturbation-batch-verify`.
An adapter can also be called from Python:

```python
from pathlib import Path
from laboratory import adapter_for_config
config = Path('/absolute/path/new-spatial-clu/assay.json')
adapter = adapter_for_config(config)
selection = dict(specimen='GSM9659884', target='Clu',
                 regionIDs=['region-1-0'], timepoint='study-endpoint')
plan = adapter.compile(config, selection)
run = adapter.predict(config, {}, Path('/absolute/path/experiments'), selection)
adapter.reveal(run, {})
adapter.verify(run, {})
```

Native and adapter identities are sealed. Retain the complete directory, prepared
source, original binaries/libraries and exact adapter files. Downloaded UI JSON
is only a summary. This is computational holdout and UI blinding, not secure
escrow: retained local source files contain the later observations. Hash receipts
are integrity checks, not third-party signatures. Failed runs and comparisons
remain records; native replay must not overwrite predictions.

## Evidence at the molecular boundary

Each typed transition contains provenance, model identity, assumptions,
uncertainty and its own evidence status:

- Measured guide RNA → assigned Clu knockout: **HYPOTHESIS**. Functional knockout
  per cell is not confirmed by a positive guide barcode.
- Training RNA plus query control → regional RNA response: **MODEL INFERENCE**.
- Knockout → binding, reaction or pathway mechanism: **UNAVAILABLE**.
- RNA → growth, survival, adhesion, forces or phenotype: **UNAVAILABLE**.

This first molecular adapter supports a real gene perturbation, not ligand binding
or compound dosing. It reuses the established RNA owner. Predictions are regional
means displayed at measured cell locations, not single-cell forecasts. Individual
endpoint UMI are separately available after reveal. Mixed cell composition,
sparse controls, uncertain barcode assignment and absent predictive distributions
limit interpretation. Calibration is unavailable. GEO's WT genotype label and
the paper's Cas9 description are not silently reconciled; accession-labelled
biological units are used without inferring a genotype.

## Shared extensions and hard gates

`ExperimentCampaign` expands a supported intervention matrix with explicit
hypothesis, fixed success criterion and simulation repetitions. It writes all
registrations/predictions before the reveal barrier, retains partial failures,
can resume reveal without refitting, and replays every arm. Deterministic
repetitions never increase biological sample size. The present molecular source
supports one target/time/region; arbitrary dose or time sweeps are rejected.
The next-region policy ranks disagreement between existing models. It is a
hypothesis, not calibrated uncertainty or demonstrated active-learning gain.

`import_spatial_table.py` accepts source-declared measured RNA or protein CSV
panels with explicit coordinates, units and missingness. Blank entries stay
missing and measured zero stays zero. Native admission is tested with fixtures;
a real spatial proteomics cohort and representation-learning tasks are not yet
qualified. The native hierarchy accommodates all five entity levels and
modalities; no multimodal foundation model is claimed.

`qualification.py` registers the current [Arc 2026 contract](https://arcinstitute.org/news/virtual-cell-challenge-2026):
unperturbed query plus CRISPRi target IDs, unseen perturbed cellular contexts,
complete training provenance, biological-unit separation and pinned model,
input and official scorer revision. Training-like contexts are rejected.
Official challenge artifacts and the pinned 2026 `cell-eval` scorer still need
admission and execution. No official score or zero-shot performance is available.
The eight-donor Kang assay remains a permanent regression, not this qualification.

The native mechanobiology participant interface defines private prepare,
checkpoint-bound release and abort with per-channel evidence. Bidirectional
Matter execution and biological constitutive laws remain unimplemented. Existing
one-way mechanics → geometry → transport remains separately replayable.
