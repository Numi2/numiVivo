# NumiVivo implementation status — 2026-09-04

## Status class

Foundational source implementation. The repository contains production-oriented contracts and substantial runtime code, but it has not received the first package-wide compiler, Metal shader, numerical, integration, or performance verification pass.

This document distinguishes source presence from verified capability.

## Repository safety boundary

The repository is computational research software. It does not authorize physical implementation. It must not be used as evidence of clinical safety, efficacy, biological containment, regulatory compliance, or environmental acceptability.

The current mechanism library and examples are sequence-free. They use abstract signals, parts, compartments, populations, and parameters. No nucleotide sequence, culture condition, transformation method, delivery protocol, dosing instruction, or patient-specific treatment plan is provided.

## First verification gate

The first external integration pass should run in this order:

1. Swift package manifest and C++ target compilation.
2. Swift 6 concurrency diagnostics.
3. Metal source compilation for every resource file.
4. ABI size and alignment inspection for shared Swift/Metal/C records.
5. ProgramPack compile/inspect round trip.
6. Declarative example source decoding.
7. Exact SSA bounded event step.
8. Population and partition single-step smoke execution.
9. Checkpoint encode/decode round trip.
10. Campaign compile and ledger verification.
11. Coupled prepare/stage/release transaction.
12. Determinism and rollback checks.

This work has intentionally not been run in the current development pass, following the instruction to prioritize implementation.

## Release blockers

Before a tagged release, the following are mandatory:

- package builds on the declared macOS and iOS deployment targets;
- all Metal kernels compile into a versioned library;
- no Swift 6 data-race diagnostics;
- C ABI headers compile as C and C++;
- source examples pass schema and semantic validation;
- ProgramPack and checkpoint readers reject malformed corpus inputs;
- stochastic reproducibility and distribution checks;
- deterministic and spatial convergence studies;
- transaction rollback fault injection;
- memory-capacity and throughput benchmarks on named Apple-silicon devices;
- standards-export validation;
- explicit license and third-party notices;
- threat-model review;
- scientific limitation review.
